# DevOps Capstone Project

[![Build Status](https://github.com/OumariMahmoud/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/OumariMahmoud/devops-capstone-project/actions/workflows/ci-build.yaml)

## Project Name

Customer Accounts Microservice

## Project Overview

This project is a Customer Accounts microservice developed as part of the DevOps Capstone Project.

The project demonstrates RESTful API development, automated testing, continuous integration, Docker containerization, Kubernetes deployment, and continuous delivery.

## Objectives

- Develop a Customer Accounts microservice.
- Implement REST APIs for account management.
- Automate testing with GitHub Actions.
- Apply code quality and security checks.
- Build and deploy the application using Docker and Kubernetes.
- Implement a CI/CD pipeline for automated deployment.
